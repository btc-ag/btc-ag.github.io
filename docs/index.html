Sovereign Architecture Advisor (SAA)

Ein interaktiver Wizard zur Bewertung und Empfehlung souveräner Cloud-Architekturen für Unternehmensanwendungen - Fokus auf europäische Datensouveränität.

Hilft Organisationen bei der Evaluierung und dem Vergleich von Cloud-Anbietern, insbesondere europäischer und souveräner Alternativen, basierend auf Multi-Kriterien-Analysen.

Wählen Sie Anwendungen aus, konfigurieren Sie Komponenten, legen Sie Sizing-Parameter fest und erhalten Sie gewichtete Empfehlungen mit detaillierten Kostenschätzungen.

Sovereign Cloud Compass (SCC)

Ein interaktives Tool zur Bewertung und Auswahl von Cloud-Anbietern basierend auf der Balance zwischen Kontrolle/Souveränität und Performance-Fähigkeiten.

Bewerten Sie Cloud-Anbieter über zwei Dimensionen - Souveränität und Performance - mit dynamischer Gewichtung. 2D-Matrix-Visualisierung macht komplexe Entscheidungen transparent und nachvollziehbar.

Filterung nach Anbieter-Kategorie und transparente Scoring-Methodik für über 14 Cloud-Provider. Ideal für strategische IT-Entscheidungen.

featuretoggle

A simple, lightweight feature toggle framework for ABAP - enabling continuous delivery in SAP environments.

Toggle features in ABAP code at runtime, delivering potentially unfinished features in a deactivated state to production. Perfect for implementing CI/CD practices in SAP landscapes.

Includes ABAP backend and UI5 GUI to manage toggle states with an intuitive interface.
