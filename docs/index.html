featuretoggle

A simple, lightweight feature toggle framework for ABAP

With this framework you can toggle features in ABAP-Code at runtime. This enables you to continuously deliver (potentially unfinished) Features in a deactivated state into the production system. This repository includes the ABAP backend and a UI5 GUI to manage toggle states.

Sovereign Architecture Advisor (SAA)

Ein interaktiver Wizard zur Bewertung und Empfehlung souveräner Cloud-Architekturen für Unternehmensanwendungen.

Das Tool hilft Organisationen bei der Evaluierung und dem Vergleich von Cloud-Anbietern - insbesondere europäischer und souveräner Alternativen - basierend auf Multi-Kriterien-Analysen. Benutzer können Anwendungen auswählen, Komponenten konfigurieren, Sizing-Parameter festlegen und erhalten gewichtete Empfehlungen mit Kostenschätzungen.

Sovereign Cloud Compass (SCC)

Ein interaktives Tool zur Bewertung und Auswahl von Cloud-Anbietern basierend auf der Balance zwischen Kontrolle/Souveränität und Performance-Fähigkeiten.

Das Tool ermöglicht die Bewertung von Cloud-Anbietern über zwei Dimensionen - Souveränität und Performance - mit dynamischer Gewichtung. Es bietet eine 2D-Matrix-Visualisierung, Filterung nach Anbieter-Kategorie und transparente Scoring-Methodik für über 14 Cloud-Provider.
